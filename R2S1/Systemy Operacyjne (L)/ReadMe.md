# Systemy Operacyjne (L)

> Grade: **5.0** &nbsp;·&nbsp; [dr inż. Marcin Pazera](https://scholar.google.com/citations?user=qYxHaXUAAAAJ)

Operating systems course. Covered Windows shell scripting (CMD/batch), PowerShell, and Bash; file system operations; process and user management; and C/C++ programs interfacing with OS APIs for directory traversal, file metadata, and system information queries.
