# Podstawy Modelowania Programów (L)

> Grade: **4.0** &nbsp;·&nbsp; [dr inż. Łukasz Hładowski](https://scholar.google.com/citations?user=W8oivM0AAAAJ)

Design patterns course in **Java**. Covered major GoF creational, structural, and behavioral patterns: Factory, Abstract Factory, Builder, Decorator, Composite, Adapter, Facade, State, Observer, and Strategy. Each lab implemented one or more patterns with multiple real-world scenario variations.
