# Testowanie i rozwój aplikacji (L)

> Grade: **5.0** &nbsp;·&nbsp; dr inż. Jacek Bieganowski

Software testing course in **Java**. Covered unit testing with JUnit 5, test doubles (stubs, mocks with Mockito), and end-to-end UI testing with **Selenium WebDriver** using the Page Object pattern. Test subjects included a chess engine (bishop attack logic, board editor) and real-world websites (UZ plan, rezerwacjazg.pl, Wikipedia).
